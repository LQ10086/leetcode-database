leetcode141 环形链表（E） 展开

思路

这题要求判断链表中是否存在环。 最常用的解法是 快慢指针法（Floyd 判圈算法）：

  1. 定义两个指针 slow 和 fast，都从头节点出发。
  2. 每次 slow 走一步，fast 走两步。
  3. 如果链表中存在环，fast 一定会在某个时刻与 slow 相遇； 如果没有环，fast 会先到达链表尾部（None）。

口诀记忆：

“快慢指针追一追，能追上就有回。”

示例讲解

输入

Plain Text
head = [3, 2, 0, -4], pos = 1
3 → 2 → 0 → -4
      ↑       ↓
      ←←←←←←

class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                return True
        return False

    bool hasCycle(ListNode *head) {
        if (!head || !head->next) return false;
        ListNode *slow = head;
        ListNode *fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        return false;
    }

leetcode21 合并两个有序链表（E） 展开

思路

这题要求把两个升序链表合并成一个新的升序链表。 最常用的做法是 双指针法：

  1. 设置一个虚拟头节点 dummy，以及一个当前节点指针 cur；
  2. 比较两条链表当前节点的值，选择较小的接到 cur.next；
  3. 移动被选中的链表指针和 cur；
  4. 当其中一条链表为空时，将另一条直接接到末尾。

口诀记忆：

“双指针并两表，小的先走保顺序。”

示例讲解

输入

Plain Text
list1 = [1, 2, 4]
list2 = [1, 3, 4]

链表结构

Plain Text
list1: 1 → 2 → 4  
list2: 1 → 3 → 4

合并过程

1️⃣ 比较 1 和 1 → 取 list1 的 1

2️⃣ 比较 2 和 1 → 取 list2 的 1

3️⃣ 比较 2 和 3 → 取 list1 的 2

4️⃣ 比较 4 和 3 → 取 list2 的 3

5️⃣ 比较 4 和 4 → 取 list1 的 4，再接上 list2 的 4

输出

Plain Text
[1, 1, 2, 3, 4, 4]

leetcode2 两数相加（M） 展开

思路

这题要求把两个非空链表表示的两个非负整数相加。数字以逆序存储，每个节点包含一个数字。输出也需以逆序形式返回结果。

常规解法是 模拟加法：

  1. 同时遍历两个链表 l1 和 l2，逐位相加；
  2. 用变量 carry 记录进位；
  3. 若某一链表较短，则视其节点值为 0；
  4. 遍历结束后，如果还有进位，需要新建一个节点保存进位值。

口诀记忆：

“逐位相加带进位，末尾别忘加一位。”

示例讲解

输入

Plain Text
l1 = [2, 4, 3]
l2 = [5, 6, 4]

代表的数字分别是 342 和 465。

逐位相加过程：

Plain Text
2 + 5 = 7
4 + 6 = 10 → 写 0 进 1
3 + 4 + 1 = 8

输出：

Plain Text
[7, 0, 8]

对应结果：807

            cur.next = ListNode(s % 10)

        return dummy.next

leetcode92 反转链表 II（M） 展开

思路

这题要求在 指定区间 [left, right] 内反转链表的一部分，其他部分保持不变。

可使用 一次遍历 + 局部反转 的技巧：

  1. 使用虚拟头节点 dummy，方便处理头部反转的情况；
  2. 先移动到反转起点的前一个节点 pre；
  3. 利用头插法或标准反转法反转 [left, right] 区间；
  4. 最后重新连接三部分链表。

口诀记忆：

“定位 pre，头插反转，再连前后。”

示例讲解

输入

Plain Text
head = [1, 2, 3, 4, 5], left = 2, right = 4

反转过程：

Plain Text
原链表：1 → 2 → 3 → 4 → 5
定位 pre=1，反转 [2,3,4]
反转后：1 → 4 → 3 → 2 → 5

输出：

Plain Text
[1, 4, 3, 2, 5]

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        if not head or left == right:
            return head

        dummy = ListNode(0)
        dummy.next = head
        pre = dummy

        # 1. 找到反转起点的前一个节点 pre
        for _ in range(left - 1):
            pre = pre.next

        # 2. 反转 [left, right] 区间
        cur = pre.next
        prev = None
        for _ in range(right - left + 1):
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        # 3. 连接前后部分
        pre.next.next = cur
        pre.next = prev

        return dummy.next

        pre->next->next = cur;

leetcode138 复制带随机指针的链表（M） 展开

思路

这题要求复制一个带随机指针的链表，每个节点除了 next 外，还有一个 random 指针，可能指向任意节点或 None。

常用的做法是 三步法克隆链表：

  1. 复制节点并插入原节点后面： 将每个节点的复制品插入原节点之后，例如 A -> B -> C → A -> A' -> B -> B' -> C -> C'
  2. 复制 random 指针： 若原节点的 random 指向 X，则复制节点的 random 指向 X.next。
  3. 拆分链表： 将交织在一起的链表拆分为原链表和复制链表两部分。

口诀记忆：

“原后插，连 random，再拆开。”

示例讲解

输入链表：

Plain Text
A(random→C) → B(random→A) → C(random→B)

第一步插入：

Plain Text
A → A' → B → B' → C → C'

第二步复制 random：

Plain Text
A'.random = A.random.next = C'
B'.random = B.random.next = A'
C'.random = C.random.next = B'

第三步拆分得到：

Plain Text
A' → B' → C' （完全独立拷贝）

输出：

复制链表的头节点。

# Definition for a Node.
class Node:
    def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
        self.val = int(x)
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None
        # 第一步：复制节点并插入原节点后面
        cur = head
        while cur:
            new_node = Node(cur.val, cur.next)
            cur.next = new_node
            cur = new_node.next

        # 第二步：复制 random 指针
        cur = head
        while cur:
            if cur.random:
                cur.next.random = cur.random.next
            cur = cur.next.next

        # 第三步：拆分链表
        cur = head
        copy_head = head.next
        while cur:
            copy = cur.next
            cur.next = copy.next
            if copy.next:
                copy.next = copy.next.next
            cur = cur.next
        return copy_head

leetcode19 删除链表的倒数第 N 个节点（M） 展开

思路

这题要求删除链表的倒数第 N 个节点。

最常见做法是使用 双指针法（又称快慢指针）：

  1. 定义两个指针 fast 和 slow，都指向头节点；
  2. 让 fast 先前进 n 步，使两指针之间间隔 n；
  3. 然后同时移动 fast 和 slow，直到 fast 到达链表末尾；
  4. 此时 slow 的下一个节点即为要删除的节点，执行删除操作。

为了方便删除头节点的情况，常在开头添加一个 虚拟头节点 dummy。

口诀记忆：

“快先走 N 步，齐头并进删 slow.next。”

示例讲解

输入

Plain Text
head = [1, 2, 3, 4, 5], n = 2

过程：

Plain Text
1. fast 先走 2 步 → fast = 3, slow = 1
2. fast 和 slow 一起走 → fast = 5, slow = 3
3. 删除 slow.next → 删除 4

输出：

Plain Text
[1, 2, 3, 5]

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        dummy = ListNode(0, head)
        slow = fast = dummy
        # fast 先走 n+1 步，保证 slow 停在删除节点前一位
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            slow = slow.next
            fast = fast.next
        slow.next = slow.next.next
        return dummy.next

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}

            slow = slow->next;
            fast = fast->next;
        }

        slow->next = slow->next->next;
        return dummy.next;
    }
};
leetcode82 删除排序链表中的重复元素 II（M） 展开

思路

这题要求删除排序链表中所有重复的节点，即如果某个值出现多次，则所有该值的节点都被删除，保留只出现一次的节点。

由于链表已排序，相同元素一定是连续的。 可采用 双指针法：

  1. 使用虚拟头节点 dummy 方便处理头部重复情况；
  2. 定义 pre 指针指向当前已处理好的最后一个不重复节点；
  3. 使用 cur 遍历链表，当 cur 和 cur.next 的值相等时，循环跳过重复部分；
  4. 最后将 pre.next 连接到下一个不重复节点。

口诀记忆：

“重复全删不留影，pre 连到不重复。”

示例讲解

输入

Plain Text
head = [1, 2, 3, 3, 4, 4, 5]

过程

Plain Text
1 → 2 → 3 → 3 → 4 → 4 → 5  
删除重复的 3 和 4  
结果：1 → 2 → 5

输出

Plain Text
[1, 2, 5]

另一个例子

Plain Text
输入: head = [1, 1, 1, 2, 3]
输出: [2, 3]

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteDuplicates(self, head: ListNode) -> ListNode:
        dummy = ListNode(0, head)
        pre = dummy
        cur = head

        while cur:
            # 检查是否存在重复
            if cur.next and cur.val == cur.next.val:
                val = cur.val
                while cur and cur.val == val:
                    cur = cur.next
                pre.next = cur
            else:
                pre = pre.next
                cur = cur.next
        return dummy.next

leetcode61 旋转链表（M） 展开

思路

这题要求将链表向右旋转 k 个位置。

核心思路：

  1. 首先统计链表长度 n；
  2. 实际旋转次数为 k % n（若 k 是 n 的倍数，则无需旋转）；
  3. 将链表首尾相连，形成环；
  4. 从头开始走 n - k 步，断开环，新头节点即为旋转后的头节点。

口诀记忆：

“连成环，走 n-k，断开即新头。”

示例讲解

输入

Plain Text
head = [1, 2, 3, 4, 5], k = 2

过程

Plain Text
原链表：1 → 2 → 3 → 4 → 5  
连成环：1 → 2 → 3 → 4 → 5 → (回到1)  
长度 n = 5，实际旋转 k = 2 → 走 n-k = 3 步  
走三步到节点 3，断开 3 与 4 的连接：
新链表：4 → 5 → 1 → 2 → 3

输出

Plain Text
[4, 5, 1, 2, 3]

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def rotateRight(self, head: ListNode, k: int) -> ListNode:
        if not head or not head.next or k == 0:
            return head

        # 1. 计算链表长度
        n = 1
        cur = head
        while cur.next:
            cur = cur.next
            n += 1

        # 2. 形成环
        cur.next = head

        # 3. 计算实际需要移动的步数
        k = k % n
        steps_to_new_head = n - k

        # 4. 找到新头并断开环
        new_tail = head
        for _ in range(steps_to_new_head - 1):
            new_tail = new_tail.next
        new_head = new_tail.next
        new_tail.next = None

        return new_head

 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}

        if (!head || !head->next || k == 0) return head;

        // 1. 计算链表长度
        int n = 1;
        ListNode* cur = head;
        while (cur->next) {
            cur = cur->next;
            n++;
        }

        // 2. 形成环
        cur->next = head;

        // 3. 计算实际移动步数
        k = k % n;
        int steps_to_new_head = n - k;

        // 4. 找到新头并断开环
        ListNode* new_tail = head;
        for (int i = 0; i < steps_to_new_head - 1; ++i) {
            new_tail = new_tail->next;
        }
        ListNode* new_head = new_tail->next;
        new_tail->next = nullptr;

        return new_head;
    }

思路

这题要求根据给定值 x 将链表分隔成两部分：所有小于 x 的节点排在前面，其余节点排在后面，且保持原有相对顺序。

最简洁的做法是使用 双链表拼接法：

  1. 定义两个虚拟头节点 small_head 和 large_head，分别存放小于 x 的节点和大于等于 x 的节点；
  2. 遍历原链表，将节点按值加入对应链表；
  3. 最后将两部分拼接起来，并将 large 部分尾节点的 next 设为 None。

口诀记忆：

“小大分箱走一遍，最后拼接链成链。”

示例讲解

Plain Text
head = [1, 4, 3, 2, 5, 2], x = 3

过程

Plain Text
小于 3 的节点：1 → 2 → 2
大于等于 3 的节点：4 → 3 → 5
拼接结果：1 → 2 → 2 → 4 → 3 → 5

输出

Plain Text
[1, 2, 2, 4, 3, 5]

class Solution:
    def partition(self, head: ListNode, x: int) -> ListNode:
        small_head = ListNode(0)
        large_head = ListNode(0)
        small = small_head
        large = large_head

        while head:
            if head.val < x:
                small.next = head
                small = small.next
            else:
                large.next = head
                large = large.next
            head = head.next

        # 拼接两部分
        large.next = None
        small.next = large_head.next
        return small_head.next

leetcode146 LRU 缓存机制（M） 展开

思路

这题要求实现一个 LRU（Least Recently Used）缓存机制，即：

  1. 当缓存容量满时，删除最久未使用的键；
  2. 每次访问或插入数据时，该数据都视为“最近使用”。

要实现 O(1) 时间复杂度的 get 和 put 操作，可以使用：

  1. 哈希表（dict / unordered_map） 存储键与节点的映射关系；
  2. 双向链表 维护节点的访问顺序（越靠前表示越常用）。

操作逻辑：

  1. get(key)：若存在则将节点移到链表头（表示最近使用）；
  2. put(key, value)：
  3. 若存在则更新值并移动到头部；
  4. 若不存在则新建节点插入头部，若超出容量则删除链表尾部节点。

口诀记忆：

“哈希查，链表调，头插尾删最常招。”

示例讲解

输入

Plain Text
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1, 缓存是 {2=2, 1=1}
lRUCache.put(3, 3); // 删除键 2, 缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 删除键 1, 缓存是 {3=3, 4=4}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4

Python

Python
class DLinkedNode:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = {}
        self.capacity = capacity
        # 使用伪头尾节点简化操作
        self.head = DLinkedNode()
        self.tail = DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _add_node(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node):
        prev = node.prev
        nxt = node.next
        prev.next = nxt
        nxt.prev = prev

    def _move_to_head(self, node):
        self._remove_node(node)
        self._add_node(node)

    def _pop_tail(self):
        node = self.tail.prev
        self._remove_node(node)
        return node

    def get(self, key: int) -> int:
        node = self.cache.get(key)
        if not node:
            return -1
        self._move_to_head(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        node = self.cache.get(key)
        if not node:
            new_node = DLinkedNode(key, value)
            self.cache[key] = new_node
            self._add_node(new_node)
            if len(self.cache) > self.capacity:
                tail = self._pop_tail()
                del self.cache[tail.key]
        else:
            node.value = value
            self._move_to_head(node)

#include <unordered_map>
using namespace std;

struct DLinkedNode {
    int key, value;
    DLinkedNode* prev;
    DLinkedNode* next;
    DLinkedNode(int _key, int _value): key(_key), value(_value), prev(nullptr), next(nullptr) {}
};

class LRUCache {
private:
    unordered_map<int, DLinkedNode*> cache;
    DLinkedNode* head;
    DLinkedNode* tail;
    int capacity;

    void addNode(DLinkedNode* node) {
        node->prev = head;
        node->next = head->next;
        head->next->prev = node;
        head->next = node;
    }

    void removeNode(DLinkedNode* node) {
        DLinkedNode* prev = node->prev;
        DLinkedNode* next = node->next;
        prev->next = next;
        next->prev = prev;
    }

    void moveToHead(DLinkedNode* node) {
        removeNode(node);
        addNode(node);
    }

    DLinkedNode* popTail() {
        DLinkedNode* node = tail->prev;
        removeNode(node);
        return node;
    }

public:
    LRUCache(int capacity): capacity(capacity) {
        head = new DLinkedNode(0, 0);
        tail = new DLinkedNode(0, 0);
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        if (!cache.count(key)) return -1;
        DLinkedNode* node = cache[key];
        moveToHead(node);
        return node->value;
    }

    void put(int key, int value) {
        if (!cache.count(key)) {
            DLinkedNode* node = new DLinkedNode(key, value);
            cache[key] = node;
            addNode(node);
            if (cache.size() > capacity) {
                DLinkedNode* tailNode = popTail();
                cache.erase(tailNode->key);
                delete tailNode;
            }
        } else {
            DLinkedNode* node = cache[key];
            node->value = value;
            moveToHead(node);
        }
    }
};

                if node.left:
                    queue.append(node.left)

        return depth

思路

这题要求判断两棵二叉树是否结构完全相同且节点值相同。

可用 递归（DFS） 实现：

  1. 若两节点都为空，则相同；
  2. 若一个为空另一个非空，则不同；
  3. 若两个节点的值不同，则不同；
  4. 否则递归比较左右子树是否相同。

也可用 队列（BFS） 实现：每次同时取出两个节点比较，并同步加入它们的左右子节点。

口诀记忆：

“空空相同，空非不同，值不同也不同，左右递归判同。”

Plain Text

结构相同且值相等，因此输出 True。

Plain Text
p = [1, 2]
q = [1, null, 2]

结构不同，输出 False。

    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class BSTIterator:
    def __init__(self, root: TreeNode):
        self.stack = []
        self._leftmost_inorder(root)

    def _leftmost_inorder(self, node):
        while node:
            self.stack.append(node)
            node = node.left

        node = self.stack.pop()
        val = node.val
        if node.right:

        return val

思路

这题要求计算完全二叉树的节点总数。完全二叉树的性质是：除最后一层外，所有层都是满的，且最后一层节点从左到右连续。

有两种解法：

  1. 递归法（利用完全二叉树特性）：
  2. 分别计算左子树和右子树的高度；
  3. 若左右高度相等，则左子树为满二叉树；否则右子树为满二叉树；
  4. 利用公式计算满二叉树节点数：2^h - 1。 平均复杂度为 O(log² n)。
  5. 常规遍历法（DFS/BFS）：直接遍历所有节点计数，时间复杂度 O(n)。

口诀记忆：

“左右高相等，左满加右算；不等则右满，递归左边算。”

   / \  /

        self.left = left
        self.right = right

思路

这题要求在一棵二叉树中找到两个节点 p 和 q 的最近公共祖先（Lowest Common Ancestor, LCA）。

核心思路是 自底向上递归搜索：

  1. 若当前节点为空或等于 p / q，则返回当前节点；
  2. 递归查找左子树与右子树：
  3. 若左右递归结果都非空，说明 p 和 q 分别位于两侧，当前节点就是最近公共祖先；

此方法时间复杂度为 O(n)，空间复杂度 O(h)（递归栈深度）。

“左右各找祖先点，两边都有当前现。”

思路

  1. 层序遍历二叉树；

from collections import defaultdict

class Solution:
    def calcEquation(self, equations, values, queries):
        graph = defaultdict(dict)
        # 建图
        for (a, b), val in zip(equations, values):
            graph[a][b] = val
            graph[b][a] = 1 / val

        def dfs(x, y, visited):
            if x not in graph or y not in graph:
                return -1.0
            if y in graph[x]:
                return graph[x][y]
            for nei, val in graph[x].items():
                if nei in visited:
                    continue
                visited.add(nei)
                res = dfs(nei, y, visited)
                if res != -1.0:
                    return val * res
            return -1.0

        res = []
        for x, y in queries:
            res.append(dfs(x, y, set([x])))
        return res

思路

题目要求判断是否能完成所有课程，即给定课程依赖关系 prerequisites，是否能构成一个无环有向图（DAG）。

若课程依赖存在环，则无法完成所有课程。

常用两种算法：

  1. 拓扑排序（BFS） —— Kahn 算法：
  2. 统计每个节点的入度；
  3. 将所有入度为 0 的节点入队；
  4. 每取出一个节点，将其相邻节点的入度减 1；若减至 0 则入队；
  5. 若最终处理的节点数等于课程数，说明无环，返回 True，否则 False。
  6. DFS 检测环 —— 通过递归检测是否存在回到当前路径的节点。

思路

  1. BFS 拓扑排序（Kahn 算法） —— 推荐：
  2. 统计入度并构建邻接表；
  3. 将所有入度为 0 的课程入队；

leetcode909 蛇梯棋（M） 展开

思路

给定一个 n x n 的棋盘，编号从 1 → n²，编号从左下角开始，走向“B型折线（Z字形）”：

  1. 底行从左到右递增；
  2. 下一行从右到左；
  3. 如此交替直至顶行。

你从格子 1 出发，每次投骰子前进 1..6 步；若落到的格子有蛇/梯子（board[r][c] != -1），则立刻传送到对应编号。求到达或越过 n² 的最少投掷次数，不可达返回 -1。

这是一道标准的 无权最短路 问题，使用 BFS：

  1. 先实现 idx → (r,c) 的转换（按题目给定的“下到上、左右交替”的编号方式）；
  2. 从编号 1 开始入队，按层（步数）扩展每个状态 cur 的 6 个后继 cur+1..cur+6；
  3. 若后继格子存在蛇/梯子，跳到目标编号；
  4. 用 visited 防止重复。首次到达 n² 即返回当前层数。

时间复杂度 O(n²)，空间复杂度 O(n²)。

口诀记忆：

“折线映射先搞定，BFS 六分支；遇梯就飞跃，首次到顶即答案。”

示例讲解

以题面示例为例（略），BFS 分层扩张，数层数（投掷次数）即可得到最短步数。

from collections import deque

class Solution:
    def snakesAndLadders(self, board: list[list[int]]) -> int:
        n = len(board)

        def id_to_rc(s: int) -> tuple[int, int]:
            # s: 1-based index → (r, c)
            s -= 1
            r = n - 1 - s // n
            c = s % n
            if ((n - 1 - r) % 2) == 1:  # 奇偶行翻转（自下而上数）
                c = n - 1 - c
            return r, c

        visited = set([1])
        q = deque([(1, 0)])  # (index, steps)
        target = n * n

        while q:
            cur, steps = q.popleft()
            if cur == target:
                return steps
            for dice in range(1, 7):
                nxt = cur + dice
                if nxt > target:
                    continue
                r, c = id_to_rc(nxt)
                if board[r][c] != -1:
                    nxt = board[r][c]
                if nxt not in visited:
                    visited.add(nxt)
                    q.append((nxt, steps + 1))
        return -1

    int snakesAndLadders(vector<vector<int>>& board) {

            return pair<int,int>(r, c);

                int nxt = cur + d;

易错点

  1. 坐标映射方向：编号从底行左→右开始，下一行方向反转；常见错误是把奇偶判断写反。
  2. 落地即传送：骰子落到有蛇/梯子的格子，要立即跳转再继续 BFS；这个跳转后的编号才用于 visited。
  3. 不可越界：cur + d 超过 n² 的步数需忽略。

思路

这题与“单词接龙（LeetCode 127）”类似，是一个最短路径搜索问题。 给定起始基因 start、目标基因 end，以及基因库 bank，每次只能改变一个字符，且每次变化后的基因必须存在于基因库中。求从 start 到 end 的最少变化次数，若无法到达返回 -1。

由于每次变化的代价相同，因此最适合使用 BFS（广度优先搜索）：

  1. 将基因库放入 set 以便 O(1) 查询；
  2. 从起点开始 BFS，每次尝试修改 8 个位置中的一个字符（A/C/G/T 四种可能）；
  3. 若新基因在 bank 中且未访问，则加入队列；
  4. 层层扩展，直到到达目标基因。

时间复杂度：O(4 * 8 * n) ≈ O(n)，其中 n 为基因库大小。 空间复杂度：O(n)。

“单步四变 BFS，入库方可行。”

from collections import deque

class Solution:
    def minMutation(self, start: str, end: str, bank: list[str]) -> int:
        bank_set = set(bank)
        if end not in bank_set:
            return -1

        genes = ['A', 'C', 'G', 'T']
        queue = deque([(start, 0)])
        visited = {start}

        while queue:
            cur, steps = queue.popleft()
            if cur == end:
                return steps
            for i in range(8):
                for g in genes:
                    if g != cur[i]:
                        nxt = cur[:i] + g + cur[i+1:]
                        if nxt in bank_set and nxt not in visited:
                            visited.add(nxt)
                            queue.append((nxt, steps + 1))
        return -1

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head

        # 快慢指针找中点
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None  # 断开

        left = self.sortList(head)
        right = self.sortList(mid)
        return self.merge(left, right)

    def merge(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        cur = dummy
        while l1 and l2:
            if l1.val < l2.val:
                cur.next, l1 = l1, l1.next
            else:
                cur.next, l2 = l2, l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        return dummy.next

 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}

        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;

        ListNode* mid = slow->next;
        slow->next = nullptr;

        ListNode* left = sortList(head);
        ListNode* right = sortList(mid);
        return merge(left, right);

                cur->next = l1;
                l1 = l1->next;
            } else {

                l2 = l2->next;

            cur = cur->next;

leetcode35 搜索插入位置（E） 展开

思路

在有序不重复数组 nums 中查找 target 的索引；若不存在，返回其应当插入的位置，使数组仍保持有序。

这是标准的**二分查找下界（lower_bound）**问题：

  1. 维护区间 [l, r)（左闭右开）或 [l, r]（左闭右闭）；
  2. 令 mid = (l + r) // 2；
  3. 若 nums[mid] < target，令 l = mid + 1，否则 r = mid（或 r = mid - 1 视区间而定）；
  4. 结束时 l 即为 target 的插入位置。

时间复杂度 O(log n)，空间 O(1)。

口诀：

“找下界：小的丢左端，大的丢右端，落点即答案。”

思路

双栈法：

  1. 主栈存所有元素；

class MinStack:
    def __init__(self):
        self.st = []
        self.minSt = []

    def push(self, val: int) -> None:
        self.st.append(val)
        if not self.minSt:
            self.minSt.append(val)
        else:
            self.minSt.append(min(val, self.minSt[-1]))

    def pop(self) -> None:
        self.st.pop()
        self.minSt.pop()

    def top(self) -> int:
        return self.st[-1]

    def getMin(self) -> int:
        return self.minSt[-1]

        st.pop(); mins.pop();
    }

    int getMin() { return mins.top(); }
